# תשבץ ישראלי דינמי

מה יש כאן:

1. `tashbetz-dynamic.html` - עמוד משחק מלא, דינמי, בעברית/RTL.
2. `crosswords.json` - מאגר נושאים, מילים והגדרות לקהל ישראלי.

## איך מפעילים

שים את שני הקבצים באותה תיקייה באתר שלך:

```text
tashbetz-dynamic.html
crosswords.json
```

פתח את `tashbetz-dynamic.html` דרך שרת/אתר, למשל GitHub Pages, Lovable, Netlify וכו׳.

חשוב: אם פותחים ישירות מהמחשב עם `file://`, הדפדפן עלול לחסום טעינת JSON. באתר אמיתי זה יעבוד.

## איך מוסיפים תשבץ חדש

בתוך `crosswords.json`, מוסיפים אובייקט חדש ל־`packs`:

```json
{
  "id": "my-topic",
  "title": "שם התשבץ",
  "subtitle": "תיאור קצר",
  "audience": "משפחות וילדים",
  "difficulty": "קל",
  "hints": 3,
  "gridSize": 13,
  "words": [
    { "answer": "שמש", "clue": "זורחת בשמיים" },
    { "answer": "ים", "clue": "מקום לשחייה" }
  ]
}
```

## כללי תוכן בעברית

- עדיף תשובות של 3–9 אותיות.
- בלי רווחים בתשובות. למשל `תלאביב` ולא `תל אביב`.
- המנוע מנקה ניקוד, רווחים ומקפים.
- המנוע מקבל גם אותיות סופיות וגם רגילות בקלט המשתמש.
- כדי שהתשבץ ייבנה טוב, צריך הרבה אותיות משותפות בין מילים.

## למה זה עדיף מהקוד הקודם

בקוד הקודם המילים והמיקומים היו נעולים בתוך מערך קבוע ב־HTML. כאן:

- התוכן נמצא ב־JSON.
- אפשר להוסיף נושאים בלי לגעת בקוד המשחק.
- המנוע מנסה לבנות פריסה חדשה בכל פעם.
- יש התאמות לעברית, RTL ואותיות סופיות.
